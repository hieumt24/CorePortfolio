# CorePortfolio Frontend

The frontend for the CorePortfolio application, built to provide a seamless and interactive user experience for tracking cross-asset investments.

## Tech Stack

- **Framework:** [React 19](https://react.dev/)
- **Language:** [TypeScript](https://www.typescriptlang.org/)
- **Bundler:** [Vite](https://vitejs.dev/)
- **Routing:** [React Router](https://reactrouter.com/)
- **Charts:** [Recharts](https://recharts.org/)
- **Authentication:** JWT handling (`jwt-decode`)

## Setup & Execution

### Install Dependencies
```bash
npm install
```

### Run Development Server
```bash
npm run dev
```

### Build for Production
```bash
npm run build
```

## Linting
To run the ESLint checks:
```bash
npm run lint
```
